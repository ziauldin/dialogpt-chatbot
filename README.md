# 💬 DialoGPT Chatbot

A Streamlit chat app built on Microsoft's DialoGPT-medium. It keeps the conversation in session history, shows it in a custom-styled chat window, and generates each reply locally with Hugging Face Transformers and PyTorch. The repo also includes a small script that loads a tab-separated dialog dataset, cleans it, and saves a local copy of the model.

## ✨ Features
- 🤖 Replies generated by `microsoft/DialoGPT-medium`, loaded once and cached
- 🗂️ Chat history kept in Streamlit session state
- 🎨 Custom CSS chat bubbles, gradient send button, and auto-scroll
- 🧹 `chatbot.py` loads and cleans `dialogs.txt` (about 3,700 question and answer pairs), makes a train/test split, runs a test prompt, and saves the model to `saved_dialoGPT_model/`

## 🚀 Run locally

```bash
git clone https://github.com/ziauldin/dialogpt-chatbot.git
cd dialogpt-chatbot
pip install -r requirements.txt
streamlit run app.py
```

The first run downloads the DialoGPT-medium weights (about 1.5 GB) from Hugging Face.
